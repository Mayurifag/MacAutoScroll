What to check
  1. Iframe (top section): manifest sets "all_frames": true; the content script runs inside the iframe.
  2. Middle-click inside the iframe → iframe content scrolls (overlay + cursor live inside the iframe).
  3. Middle-click on the dark page area outside the iframe → outer page scrolls (use the filler text).
  4. In Settings, enable Disable inside iframes. Reload. Middle-click inside the iframe should now do nothing; outside still scrolls.
  5. Fullscreen (bottom section): click Enter fullscreen. Numbered colored bands cover the screen.
  6. Middle-click inside fullscreen — overlay attaches to document.fullscreenElement, cursor visible. Drag down — bands cycle 1 → 2 → 3 →… so scroll progress is unmistakable.
  7. Press Esc — overlay tears down cleanly. Re-test middle-click in normal mode after exit.
