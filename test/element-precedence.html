What to check
  1. Two scenarios on one page; toggle button switches between them.
  2. Page scrollable (default): body is ≈220vh. Middle-click anywhere — including inside the box — scrolls THE PAGE. The inner box does NOT scroll. Page wins when both can scroll.
  3. Page locked: click the toggle. Page now has overflow: hidden. Middle-click outside the box does nothing. Middle-click inside the box scrolls the box — fallback to nearest scrollable ancestor when the page itself cannot scroll.
  4. Verify cursor is verticalScroll in both modes.
