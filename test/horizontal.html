What to check
  1. Page uses body { overflow-x: auto } with a 300vw wide child. Body, not documentElement, is the scroller.
  2. Middle-click. Cursor is the horizontalScroll two-arrow icon (left/right only).
  3. Drag vertically — page does NOT scroll vertically; cursor stays horizontal.
  4. Drag left/right past the dead zone — page scrolls.
  5. Cursor switches to left / right single-arrow icon while moving past the dead zone.
  6. Regression: in the original bug this page used to do nothing on middle-click. The page-scroller fallback walks [scrollingElement, documentElement, body] and respects overflow styles.
