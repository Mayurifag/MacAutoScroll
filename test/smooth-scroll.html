What to check
  1. The page sets html { scroll-behavior: smooth }. Without the fix, every scrollBy call is animated — auto-scroll feels laggy/jumpy because the browser tries to tween each tiny delta.
  2. Middle-click and drag down. Scroll should feel linear and instant, not lagged. The extension saves and forces scroll-behavior: auto while active, and restores the original on stop.
  3. After releasing/clicking to stop, anchor jumps (e.g., location.hash changes) should still be smooth — verify the original value is restored.
